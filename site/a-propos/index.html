À propos d'Agregatrail

Agregatrail rassemble sur une carte le calendrier des trails en France, pour trouver une course par zone, par date, par distance et par dénivelé. C'est un projet personnel et bénévole, dont le code est ouvert.

Engagements

  • Rien n'est vendu : pas de publicité, pas d'inscription payante, pas de lien affilié, pas de revente de données.
  • Pas de compte et pas de mesure d'audience : vos listes de courses, vos week-ends disponibles et vos corrections restent dans votre navigateur (stockage local). Une liste ne quitte votre appareil que si vous partagez son lien.
  • Services tiers limités au nécessaire : les fonds de carte (IGN, OpenTopoMap, Esri), la recherche d'adresse (Base Adresse Nationale) et le calcul du temps de route (Géoplateforme IGN) reçoivent votre adresse IP quand vous les utilisez, comme pour toute carte en ligne. Aucune clé ni aucun serveur propre au site.
  • L'organisateur fait foi : chaque course renvoie vers son site officiel. Vérifiez toujours la date, le parcours et les conditions d'inscription auprès de lui.

Sources et licences

La collecte automatique ne vise que des sources dont les conditions et le fichier robots.txt autorisent la réutilisation. Elle respecte au moins 3 secondes entre deux requêtes et ne contourne aucune protection.

Méthode

  • Chaque semaine, une tâche automatique relit les sources, rassemble les formats d'une même course (même nom, même ville, même mois) et place chaque course sur la carte, dans son département et sa région.
  • Quand plusieurs sources décrivent la même course, elles se complètent : l'une apporte le jour exact, l'autre le D+ ou le site officiel.
  • La page Qualité des données montre, à chaque mise à jour, ce qui manque par région et par source, ainsi que les incohérences repérées. Une alerte est levée si une source baisse fortement ou change de format.
  • Les Nouveautés listent les courses ajoutées, les dates confirmées et les D+ trouvés depuis la semaine précédente, avec un flux Atom.

Ce qui est estimé

Toute valeur calculée par le site est signalée comme une estimation, jamais comme une donnée officielle :

  • le km-effort (distance + D+/100), la catégorie UTMB Index et les points ITRA ;
  • le temps de course, calculé d'après un chrono que vous donnez ;
  • le temps de route, en voiture et sans trafic ;
  • l'habitude de calendrier (« 3e week-end de mai ») et la date probable d'une édition pas encore annoncée ;
  • les dates marquées « à confirmer », reprises d'une édition passée ou d'une source incomplète.

Limites

  • Couverture inégale : complète en Occitanie, en PACA et en Auvergne-Rhône-Alpes, partielle ailleurs, où seules les courses déclarées aux offices de tourisme apparaissent.
  • D+ manquant pour une partie des formats, quand ni la source ni l'organisateur ne le publient.
  • Décalage : la base est mise à jour une fois par semaine ; une annulation ou un report récent peut ne pas encore y figurer.
  • Erreurs possibles dans les distances, les lieux ou le regroupement des formats, malgré les contrôles.

Contribuer

  • Une course manque, une info est fausse : le bouton « Ajouter une course » de l'accueil, ou le formulaire Compléter ou corriger une course.
  • Vous organisez une course : le même formulaire permet de corriger la date, les formats ou le D+, ou de demander le retrait de la course.
  • Une source ouverte à proposer, une idée, un bug : ouvrez une issue sur GitHub. Le code et les données sont dans le dépôt du projet.
