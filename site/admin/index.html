Même colonnes que l'export « Courses ajoutées » (au minimum nom, date, ville, distance_km). Une ligne dont l'id est « membre-123 » met à jour cette course ; une ligne sans id est ajoutée et publiée. La colonne statut (attente, publiee, refusee) est respectée si elle est remplie. Le séparateur point-virgule d'Excel est accepté.

Mise à jour de la base principale. Chaque lundi, la collecte des sources met à jour la base et le site est renvoyé sur l'hébergement. Les courses publiées ici apparaissent tout de suite sur la carte, puis entrent dans la base principale (pages par course, doublons, qualité) à la mise à jour suivante.
